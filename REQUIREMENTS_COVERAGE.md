# TRACK-IT Requirements Coverage

## Implemented in this package

| Area | Coverage |
|---|---|
| Role-based authentication | Campus User, Faculty, External Finder and Admin roles |
| College registration rules | `@gcet.edu.in` validation and College ID requirement |
| Email verification | Six-digit OTP, 10-minute expiry, resend, attempt limit |
| Lost/found reporting | Title, category, color, brand, description, location, date and image |
| Search and filters | Full-text-like API search, type/status/category/location filtering |
| AI-assisted matching | Explainable weighted text and metadata matching |
| Privacy | Public cards exclude email/phone and private claim evidence |
| Ownership claims | Submission, duplicate prevention, self-claim prevention, review |
| Review workflow | Faculty/admin approval and rejection with notes |
| Secure handover | UUID QR token, six-digit OTP, expiry, row lock and single use |
| Messaging | Claim-participant and authorized-staff messages |
| Notifications | REST notification centre and optional WebSocket delivery |
| Dashboard | Lost, found, pending claims, returned, reports and resolution rate |
| Exports | PDF and XLSX downloads |
| Assistant | Informational FAQ/intent assistant |
| Database | PostgreSQL Docker image with pgvector extension migration |
| Redis/Celery | Docker services and Celery configuration |
| Deployment | Dockerfiles, Compose stack, environment templates |
| Tests | Authentication, matching, permissions, claims, handover, notifications, chatbot |
| Responsive UI | Desktop, tablet and mobile layouts |

## Production extensions prepared but not required for the college demo

- The database enables pgvector, while the included stable matcher uses explainable text and metadata scoring. A sentence/image embedding provider can be connected later without changing the claim workflow.
- Celery and Redis are configured; the college demo performs small email/notification jobs synchronously for easier local operation.
- WebSocket notification code is included and automatically falls back to REST polling when Channels or Redis are unavailable.
- Real QR camera scanning can be added to the frontend; the current handover accepts the QR token generated by the system and displays a scannable QR code.
- Object-storage media, antivirus scanning, institutional SSO and production observability require deployment-specific credentials and infrastructure.

## Submission statement

The package implements the complete demonstrable vertical slice:

```text
Verified registration
→ Lost/found report
→ AI match suggestion
→ Private ownership claim
→ Authorized approval
→ QR + OTP handover
→ Returned status and audit notification
```
